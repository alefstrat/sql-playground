How to use SQL Playground

  • Click a table in the diagram to query it (SELECT *). Click it again to take it out.
  • Click a column to add it to SELECT. Drag a column onto a column of another table to JOIN them.
  • Double-click a table (or press its Rows button) to see its rows under the diagram. Click a cell there to filter with WHERE.
  • Use ⋯ on a column to sort, group, total or calculate.
  • Click rows in the result to write SQL that returns just those rows. Shift or Ctrl-click picks several. Esc clears.
  • Ctrl + Enter runs. CREATE, INSERT, DELETE and DROP show a preview first. Separate statements with ; to run a script.
  • Ctrl + scroll zooms the diagram. Drag empty space to move it.
